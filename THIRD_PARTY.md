# Third-party sources

Toolchecklink is designed to reuse or interoperate with existing open-source work rather than rewrite mature media-detection logic.

- TexHub Video Downloader — https://github.com/TexhubPro/texhub-video-downloader — MIT
- StreamDownloader — https://github.com/izamashidog/StreamDownloader — MIT
- The Stream Detector — https://github.com/54ac/stream-detector — MPL-2.0
- m3u8_dl — https://github.com/StasonJatham/m3u8_dl — architecture reference pending license verification
- yt-dlp — external resolver
- Streamlink — external resolver
- FFmpeg — external verification/player pipeline

Any directly reused source will retain the required upstream license/attribution.
